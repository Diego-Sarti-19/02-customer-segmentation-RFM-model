# Customer Segmentation using RFM Analysis and K-Means Clustering

## Project Overview

This project applies **RFM (Recency, Frequency, Monetary) analysis** and **unsupervised machine learning techniques** to identify customer segments based on purchasing behavior.

Using the Brazilian E-Commerce dataset, the project develops a customer segmentation model combining statistical analysis, feature engineering, and K-Means clustering.

The main goal is to transform transactional data into actionable customer insights, supporting data-driven marketing strategies, customer relationship management, and business decision-making.

## Business Problem

Understanding customer purchasing behavior is essential for improving customer retention, increasing revenue, and optimizing marketing investments.

Traditional customer classification methods often rely on predefined business rules. This project explores an unsupervised machine learning approach to identify natural customer groups based on their transactional characteristics.

The analysis aims to answer questions such as:

- Which customers generate the highest monetary value?
- Which customers purchase more frequently?
- Which customers have not purchased recently?
- Which customer groups represent higher business potential?
- How can customer segmentation support targeted marketing strategies?

## Dataset

The project uses the Brazilian E-Commerce dataset associated with Olist.

The dataset contains transactional and customer-related information, including:

- Customer identification.
- Order history and purchase dates.
- Product and order information.
- Transaction values.
- Payment information.

These data are processed and transformed into a customer-level analytical dataset for RFM modeling.

## Methodology

The project follows a structured analytical workflow.

### 1. Exploratory Data Analysis (EDA)

- Data quality assessment.
- Missing value analysis.
- Duplicate identification.
- Statistical analysis of transactional data.
- Exploration of customer purchasing patterns.

### 2. RFM Feature Engineering

Three behavioral dimensions are calculated for each customer:

| Metric | Description |
|---|---|
| Recency | Time elapsed since the customer's last purchase |
| Frequency | Number of purchases made by the customer |
| Monetary | Total monetary value generated by the customer |

These metrics provide a behavioral representation of the customer base.

### 3. Customer Scoring and Classification

Customers are evaluated using RFM metrics to identify behavioral patterns and establish customer performance classifications.

The scoring methodology supports the identification of strategic customers, high-potential customers, customers in development, and low-performance segments.

### 4. K-Means Clustering

K-Means is applied to identify groups of customers with similar purchasing characteristics.

The modeling process includes:

- Feature preparation.
- Data standardization when appropriate.
- Evaluation of different cluster configurations.
- Model fitting and customer assignment.
- Cluster profiling and interpretation.

### 5. Optimal Number of Clusters

The Elbow Method is used to evaluate the Within-Cluster Sum of Squares (WCSS) across different values of K.

Additionally, the Euclidean distance calculation is explored as a geometric approach to identifying the elbow point and evaluating the reduction in intra-cluster variability.

### 6. Customer Segmentation and Business Insights

The resulting clusters are analyzed to identify customer behavioral profiles.

The objective is to translate machine learning outputs into actionable business recommendations, supporting customer prioritization and targeted commercial strategies.
